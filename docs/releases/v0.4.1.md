# omnidevx-core v0.4.1 Release Notes

**Release Date:** 2026-10-08

## Overview

Patch release for the Claude Code session reader on Windows. In v0.4.0 the
reader never reported a session as `running` on Windows, and the release
notes said the process start time could not be read there using only the
standard library. That was wrong: Windows exposes a process's creation time,
and the reader now uses it.

## Fixed

- **Running state on Windows.** The reader verifies a live-process record by
  checking that the process exists and started when the record says it did,
  so that a stale record naming a reused process ID is ignored. That check now
  works on Windows, as it does on macOS and Linux. Sessions with a live
  process show as `running` instead of `resumable`.

## Dependencies

- Adds [`github.com/grokify/oscompat`](https://github.com/grokify/oscompat)
  v0.6.0 for the process check. It has no dependencies of its own, so the
  module's third-party surface is `gogit` and `oscompat`.

## Installation

```bash
go get github.com/plexusone/omnidevx-core@v0.4.1
```

## Migration

No API changes. If you rely on Windows never reporting `running`, note that
it now can.
