# CLAUDE.md — omnidevx-core

Repo-specific context for Claude Code sessions. Inherits from
[plexusone/.github/CLAUDE.md](https://github.com/plexusone/.github/blob/main/CLAUDE.md).

## What This Repo Is

**omnidevx-core** is the canonical event model and report pipeline for
OmniDevX — PlexusOne's developer-experience telemetry domain. It
collects and normalizes events from AI coding agents (Claude Code, Codex
CLI) and development tools (git) so frameworks like SPACE, AI-SPACE, and
DORA can be computed over one vendor-neutral event model.

Not to be confused with:
- **omnidxi** — Digital Experience Intelligence (product analytics facade)
- **omnidevx** — batteries-included engine composing all collectors (uses this repo)

## Package Overview

| Package | Purpose |
|---------|---------|
| `omnidevx` (root) | Canonical `Event` IR, `Collector` contract, periods, provenance |
| `store` | JSONL event store (`~/.plexusone/omnidevx/data/`), idempotent writes |
| `identity` | Resolves GitHub usernames, git emails, device accounts → `personId` |
| `report` | Builds `DeveloperPeriodReport` from events: daily summaries, rollups |
| `report/pricing.go` | Model pricing table for cost estimation (embedded from `pricing.json`) |
| `providers/claudecode` | Claude Code session history collector (stdlib only) |
| `providers/git` | Git commit collector with AI co-author attribution |
| `providers/genericotel` | OTLP/JSON metrics receiver for tools without dedicated providers |

## Key Types

```go
// Canonical event (omnidevx.event/v1)
type Event struct {
    ID         string            // deterministic, dedup-safe
    Type       string            // ai.* or devx.* namespace
    Timestamp  time.Time
    Attributes map[string]any    // AttrModel, AttrCostUSD, AttrInputTokens, etc.
    Provenance Provenance        // source, collection mode, confidence
}

// Period report output (omnidevx.developer-period/v1)
type DeveloperPeriodReport struct {
    Subject  Subject
    Period   Period
    Metrics  MetricSet  // Combined, BySource, ByModel
    Sources  []string
    Quality  Quality    // CoverageScore, Warnings
}

// MetricSet dimensions
type MetricSet struct {
    Combined map[string]Metric           // all sources merged
    BySource map[string]map[string]Metric // keyed by source ID
    ByModel  map[string]map[string]Metric // keyed by model name
}
```

## Common Tasks

### As a Consumer

```go
import (
    "github.com/plexusone/omnidevx-core/store"
    "github.com/plexusone/omnidevx-core/report"
)

s, _ := store.Open(store.Options{})
read, _ := s.Read(ctx, store.Query{Period: period})
r := report.Build(read.Events, report.Subject{PersonID: "person:jane"}, period)

// Access metrics
totalCost := r.Metrics.Combined["cost_usd"]
byModel := r.Metrics.ByModel["claude-opus-4-8"]["input_tokens"]
```

## Metric Keys

Standard metric keys used in `MetricSet`:

| Key | Description |
|-----|-------------|
| `messages` | AI assistant messages |
| `input_tokens` | Tokens sent to model |
| `output_tokens` | Tokens generated by model |
| `cache_read_tokens` | Tokens read from prompt cache |
| `cache_creation_tokens` | Tokens written to prompt cache |
| `cost_usd` | Total cost (observed + estimated) |
| `cost_usd_estimated` | Backfilled cost portion only |
| `sessions` | Unique session count (deduplicated) |
| `commits` | Git commits |
| `lines_added` / `lines_deleted` | LOC changes |

## Cost Estimation

When events have model + token attributes but lack `cost_usd`, the report
pipeline estimates cost from `report/pricing.json`. Estimated cost appears
in both `cost_usd` and `cost_usd_estimated` so consumers can distinguish
observed from estimated.

`LookupPricing(model)` uses exact match first, then longest-prefix match.
Suffixes like `[1m]` (extended context) and `-YYYYMMDD` (version) are
handled automatically.

## Privacy Model

**Metadata only.** No prompt text, responses, or file contents are ever
captured. This is enforced structurally (Event type has no content fields)
and by tests that fail if content-like attribute keys are added.
